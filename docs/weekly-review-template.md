# Digital Product Seller Weekly Review Template

中文说明：这是一份给闲鱼、Goofish、小红书、微信和小店数字产品卖家的免费周复盘模板。它适合记录每周销售额、毛利、最高毛利商品、主要咨询问题、退款或关闭原因，以及下周动作。

## Weekly Review Fields

| Field | 中文字段 | Why It Matters |
| --- | --- | --- |
| Week | 周次 | Keeps review records grouped by week |
| Weekly sales | 本周销售额 | Shows whether revenue is moving |
| Weekly gross profit | 本周毛利 | Shows whether costs and support are eating the sale price |
| Highest-margin product | 最高毛利商品 | Identifies which SKU deserves more focus |
| Main buyer question | 主要咨询问题 | Reveals what the listing page does not explain clearly |
| Refund or closed-order reason | 退款/关闭原因 | Shows whether the issue is price, delivery, expectation, or usage |
| Next-week action | 下周动作 | Turns review into one concrete change |
| Reviewed | 是否复盘 | Prevents collecting rows without acting |

## How to Use It

1. Fill one row every weekend.
2. Start with only real orders, real buyer questions, and real refund or closed-order reasons.
3. Choose one next-week action: change title, cover, listing description, price, delivery script, or refund boundary.
4. Review whether that action reduced repeated questions or closed orders the next week.
