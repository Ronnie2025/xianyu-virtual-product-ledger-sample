# Digital Product Seller Buyer Inquiry Log

Use this one-row template when a buyer asks about price, refund, samples, fit, delivery, or promised results before placing an order.

中文说明：这份表是给闲鱼虚拟资料卖家的售前咨询记录表。买家问太贵、能不能退款、有没有样品、适不适合、能不能包效果时，不要只在聊天里回完就忘，把问题和下一步动作记下来。

## Buyer Inquiry Fields

| Field | What to record |
| --- | --- |
| Date | Inquiry date |
| Platform | Xianyu, Goofish, Xiaohongshu, WeChat, or another channel |
| Product | The product or digital pack the buyer asked about |
| Buyer Question | The buyer's exact concern, such as price, refund, sample, fit, or promised result |
| Reply Angle | How you answered: value explanation, boundary, sample, delivery, or fit |
| Sample Proof | What proof you showed: public sample, file list, dashboard preview, or one-page sample |
| Did They Buy | Yes, no, pending, or closed |
| Follow-Up Risk | What could cause refund, dispute, or confusion |
| Review Action | What to improve next: title, cover, detail page, delivery script, refund boundary, or pricing |

## Quick Use

1. Copy one buyer's real question into the row.
2. Mark whether they bought, asked again, or closed the order.
3. Write one review action that can reduce the same question next week.
4. If you see the same question 3 times in a week, update the listing or delivery script.
